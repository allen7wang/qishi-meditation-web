This public repository contains production runtime files and licensed audio. The source repository stays private. Android is a sideloadable APK; iOS is an unsigned IPA requiring signing before installation. Neither is an App Store/TestFlight or Play Store release.

Web/PWA works in desktop/mobile browsers and supports installation to the home screen. Offline audio must be saved before disconnecting; browser-managed data may be removed by the system.
